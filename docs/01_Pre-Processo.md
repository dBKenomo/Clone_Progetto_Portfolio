# Progetto Portfolio

Svillupare una Warehouse usando PostgreSQL come Database di lavoro inoltre tutta la procedura viene fatto in totale isolamente utilizzando Docker.

## Specifiche

- File: al momento si utilizzano dei file CSV per questo progetto.
- Caricare le informazioni: il processo che viene richiesto di fare è di caricare i file nel sistema nel database e cosi poi ottenere dei dati con cui lavorare.
  - questo richiede anche il dover andare a ripulire i dati in modo adeguato;
  - fare in modo che le file siano più chiari in fase poi di analisi;
- Documentazione in modo più completo di quello che viene fatto.
